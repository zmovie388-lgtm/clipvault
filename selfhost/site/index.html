    FAQ

    Is it free and unlimited?

    Yes. Files are kept on the server for one hour and then deleted automatically.

    Why is the downloaded MP4 better than screen recording?

    You get the original stream the platform serves — full resolution and bitrate, original audio, no UI overlays.

    A YouTube link shows a "bot check" error?

    YouTube sometimes blocks data-center servers. The server owner can add a cookies.txt file, or run ClipVault on a home PC / VPS where it works normally.

    Can I download private videos?

    No. Only public videos are supported. Please respect creators' rights and each platform's terms.
